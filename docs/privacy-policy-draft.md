설정의 '내 설정·저장 목록 내보내기'로 계정 ID·이메일, 알림 설정, 관심 규칙과 저장 항목 ID 최대 1,000개를 JSON으로 저장할 수 있다. 전체 개인정보 사본은 아니며 제외 범위는 저장 전에 표시한다. 사용자 저장 파일은 서버 탈퇴나 앱 삭제로 자동 제거되지 않는다. 전체 개인정보 열람과 내보내기에 포함되지 않은 항목은 문의 채널로 요청한다.

문의 접수만으로 다른 사람의 계정 정보를 제공하거나 삭제하지 않는다. 본인 확인은 로그인된 계정 또는 해당 가입 이메일을 확인하는 방식으로 진행하는 운영 절차 초안을 별도 작성했다. 주민등록증 사본을 기본 확인 자료로 요구하는 절차는 도입하지 않았다. 문의 이메일과 불필요한 사본은 답변 완료 후 30일 이내 운영자가 삭제한다. 분쟁·법적 보관이 필요한 건은 근거·범위·기간을 따로 기록한다. 이메일 자동 삭제 연동은 없다.

권리 행사 운영안: 열람 요구를 받은 날부터 10일 이내 열람·필요한 통지를 진행한다. 정정·삭제 및 처리정지 요구는 요구를 받은 날부터 10일 이내 조치 결과를 통지한다. 법령상 제한·연기·거절 사유가 있으면 적용 사유와 이의제기방법을 안내하며, 열람의 연기·거절도 10일 이내 통지한다. 이의제기는 위 문의 이메일로 접수한다. 구체적인 통지·본인 확인·일부 제공 절차와 확인 법령은 PRIVACY_REQUEST_PROCEDURE.md에 기록했다. 공개 전 운영자의 실제 수행 절차를 확인한다.

## 보호 조치와 변경 안내

사용자별 설정과 이력은 계정 소유자 접근 정책으로 제한한다. 기기 토큰과 서버 자격 증명은 일반 공개 피드에 포함하지 않는다.

일반 사용자의 소유 데이터 접근은 계정별 정책으로 제한하고, 관리자 정보는 현재 세션과 관리자 권한을 확인한다. 정리 작업은 일반 클라이언트 API가 아닌 DB 소유자와 내부 예약만 실행할 수 있다. 서버 비밀 키를 앱 배포물에 넣지 않는다. 공급자 API 접속에는 HTTPS를 사용한다.

**운영 기준 확인:** 문의·권리 행사 요청 기록은 앞서 정한 답변 완료 후30일 이내 운영자 삭제 기준을 따른다. 분쟁·법적 보관이 필요한 예외는 근거·범위·기간을 개별 기록한다.

**미확정:** 적용 법령에 따른 접근 기록 관리 범위, 최종 변경 고지 절차와 시행일. 실측하지 않은 보안 인증이나 즉시 영구 삭제를 보장하는 문구는 넣지 않는다.

## 공개 전 점검

1. 운영자 표시 '태산이'와 공개 이메일은 사용자 지정 완료. 이 표기를 최종 고지에 반영.
2. 자동 정리 구현·활성화 완료. 외부 처리의 남은 미확정 항목과 문의 보관·처리 절차 확정.
3. 최종 내용 검토 후 로그인 없이 접근 가능한 고정 URL로 공개.
4. 앱 설정과 Google OAuth 브랜딩에 최종 URL 연결.

현재 `/about`은 기능·계정 삭제 안내이며 개인정보처리방침을 대신하지 않는다.
